# Discord Resellers — Front-End

A production-quality static front-end for **Discord Resellers — Learn. Build. Sell.**

## Included
- Responsive SaaS-style dark UI
- Sticky glass navbar + mobile menu
- Hero section with animated counters
- Configurable statistics in `script.js`
- Scroll reveal animations
- Free / Pro pricing sections
- Pro Resource Vault
- Supplier Vault with locked demo interactions
- Marketplace with clearly marked demo listings
- Seller Slots
- Animated 4-step timeline
- Community preview
- Demo review cards clearly labeled as demo content
- FAQ accordion
- Final CTA + footer
- No backend, database, authentication, payments, or API calls

## Logo
Place your real logo at:

`assets/logo.png`

A small CSS fallback mark is included if the file is missing.

## Configuration
Edit `CONFIG` in `script.js` to change the main stats.

## Important before launch
The page intentionally labels financial metrics, suppliers, products, and reviews as demo/placeholder content. Replace these with verified information before publishing.

Connect real links for:
- Discord invite
- Pro checkout
- Seller-slot checkout
- Marketplace/product pages
- Legal pages
- Support/contact

Also ensure every listed product/service complies with Discord, payment-provider, supplier/provider, and applicable local laws/terms.
